KONFIGURASI APLIKASI

Pengaturan

Hubungkan database bersama agar semua peserta melihat data yang sama.

Koneksi database

Gunakan Supabase untuk sinkronisasi lintas perangkat.

Belum dikonfigurasi
URL project dan publishable/anon key aman digunakan di browser jika kebijakan RLS pada database sudah diterapkan. Jangan pernah memasukkan service_role key di sini.

Pengaturan koneksi disimpan di browser perangkat ini. Untuk perangkat lain, masukkan URL dan key yang sama. Data peserta dan checklist disimpan di database Supabase, bukan di browser.

Akses koordinator

Login menggunakan akun Supabase Auth yang didaftarkan sebagai koordinator.

Belum login. Peserta dapat melihat data; hanya akun koordinator yang terdaftar dapat mengubah checklist.

Petunjuk setup

Langkah satu kali sebelum digunakan bersama.

  1. Buka file supabase/schema.sql di repository ini.
  2. Jalankan seluruh SQL di Supabase Dashboard → SQL Editor.
  3. Buat akun koordinator di Authentication → Users.
  4. Salin User UID akun tersebut, lalu jalankan SQL INSERT koordinator yang ada di README.
  5. Masukkan Project URL dan publishable/anon key di atas.
  6. Login sebagai koordinator. Bagikan alamat web kepada peserta untuk melihat data.
